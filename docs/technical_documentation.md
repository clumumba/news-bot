# Technical Documentation

This project uses a modular NewsBot architecture with:

- `config/settings.py` for path and environment management
- `src/data_processing/` for preprocessing, features, and validation
- `src/analysis/` for classification, sentiment, NER, and topics
- `src/language_models/` for summarization, generation, and embeddings
- `src/multilingual/` for language detection and translation
- `src/conversation/` for natural-language query handling
- `src/utils/` for evaluation, export, and visualization

The working implementation is backed by `src/nlp_pipeline/`.
